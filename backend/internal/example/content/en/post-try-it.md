# Five things to try first

1. Open [Every block a page can hold](showcase.md) in the editor and look at how each block is made.
2. Reply to the comment on [Comments and reactions](comments-and-reactions.md), and react to it.
3. Watch this blog, so the next post reaches you.
4. Press Ctrl+K and search for a word from these pages.
5. Make your own space under **Spaces** and write your first page.
