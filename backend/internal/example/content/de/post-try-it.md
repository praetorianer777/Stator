# Fünf Dinge zum Ausprobieren

1. Öffnen Sie [Alle Blöcke einer Seite](showcase.md) im Editor und sehen Sie, wie jeder Block gemacht ist.
2. Antworten Sie auf den Kommentar unter [Kommentare und Reaktionen](comments-and-reactions.md), und reagieren Sie darauf.
3. Beobachten Sie diesen Blog, damit Sie der nächste Beitrag erreicht.
4. Drücken Sie Strg+K und suchen Sie ein Wort aus diesen Seiten.
5. Legen Sie unter **Bereiche** Ihren eigenen Bereich an und schreiben Sie Ihre erste Seite.
